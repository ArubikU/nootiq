# Iconos recomendados para PWA - Nootiq

Para una implementación completa de PWA, se recomienda agregar los siguientes iconos en la carpeta `public/`:

## Iconos principales
- `icon-192x192.png` - Icono de 192x192 píxeles
- `icon-512x512.png` - Icono de 512x512 píxeles
- `apple-touch-icon.png` - Icono para dispositivos Apple (180x180)

## Iconos adicionales opcionales
- `icon-72x72.png` - Para Android Chrome
- `icon-96x96.png` - Para Android Chrome
- `icon-128x128.png` - Para Android Chrome
- `icon-144x144.png` - Para Android Chrome
- `icon-152x152.png` - Para iPad
- `icon-384x384.png` - Para Android Chrome

## Splash screens (opcional)
- `splash-640x1136.png` - iPhone 5/SE
- `splash-750x1334.png` - iPhone 6/7/8
- `splash-828x1792.png` - iPhone XR
- `splash-1125x2436.png` - iPhone X/XS
- `splash-1242x2208.png` - iPhone 6/7/8 Plus
- `splash-1242x2688.png` - iPhone XS Max
- `splash-1536x2048.png` - iPad
- `splash-1668x2224.png` - iPad Pro 10.5"
- `splash-1668x2388.png` - iPad Pro 11"
- `splash-2048x2732.png` - iPad Pro 12.9"

## Favicon
- `favicon.ico` - Favicon tradicional
- `favicon-16x16.png` - Favicon pequeño
- `favicon-32x32.png` - Favicon mediano

Actualmente el manifiesto está configurado para usar `/logo.svg` como icono principal. 
Se recomienda crear versiones específicas de estos tamaños para optimizar la experiencia PWA.
